```text
Dart >=2.7.0 <3.0.0
```

## Historical run path

With a compatible Flutter/Dart toolchain:

```bash
flutter pub get
flutter run
```

## Where to look

- `lib/` = Dart UI implementation
- `assets/` = images and fonts
- `pubspec.yaml` = dependencies and asset declarations
